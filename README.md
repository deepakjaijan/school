# 🏫 School Management System

A simple **Java-based School Management System** project that demonstrates the principles of **Object-Oriented Programming (OOP)** — Encapsulation, Inheritance, Polymorphism, and Abstraction — in a real-world context.

---

## 📌 Features
- **Student Management**: Add, view, and manage student details.
- **Teacher Management**: Assign subjects and track teacher information.
- **Role Differentiation**: Abstract `Person` class ensures clear separation of responsibilities.
- **Encapsulation**: Private fields with getters/setters for secure data handling.
- **Inheritance**: `Student` and `Teacher` classes extend `Person`.
- **Polymorphism**: Method overloading (`study()`) and overriding (`role()`).
- **Abstraction**: Abstract methods enforce implementation of roles.
